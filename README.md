#  Eldercare Management System

A full-stack web application developed to simplify elderly care management by connecting elderly users, caregivers, and family members on a single platform.

## 📌 Features

-  Secure User Authentication
-  Elder Profile Management
-  Caregiver Registration
-  Appointment Scheduling
-  Medicine Reminder
-  Health Record Management
-  Emergency Contact Support
-  Dashboard for Users

##  Tech Stack

### Frontend
- React.js
- Vite
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

##  Installation

### Clone the repository

```bash
git clone https://github.com/jassbari/Eldercare-Management-System.git
```

### Backend

```bash
cd Eldercare_project/backend
npm install
npm start
```

### Frontend

```bash
cd nursing_project/frontend
npm install
npm run dev
```

##  Environment Variables

Create a `.env` file inside the backend folder.

Example:

```
MONGODB_URI=your_mongodb_connection_string
PORT=5000
JWT_SECRET=your_secret_key
```
